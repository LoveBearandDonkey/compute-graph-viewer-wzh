跨 run 任务条匹配的可信依据

精准匹配的规则为算子在计算图上的身份（node id / 结构指纹：算子类型 + 拓扑位置），而非它在时间轴上出现的先后顺序。

图身份来自编译产物本身，不随调度顺序、局部算子增减而漂移；两侧对不上号时应明确留空，而不是给出一条看似合理实则配对错误的连线。

可行性取决于 profiling 落盘能否带稳定节点标识，拿不到时可退化为按（算子类型 + 拓扑位置 + shape）构造结构指纹；两次训练图结构本就差异较大时，部分节点没有对应物是正常现象。
