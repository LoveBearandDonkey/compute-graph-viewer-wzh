# 工具矩阵

## 训练管理与监控

| 工具名 | 路径 | 功能 |
| --- | --- | --- |
| Training Run Explainable Twin（训练运行可解释孪生） | `Profiling_Insight_and_Tool/training-run-twin-standalone/training-monitoring-v2.html` | 训练监控大盘：整网 3D deck 正视图、集群热力矩阵、MoE 专家负载（Router 倾斜）等实时监控卡片；「问题诊断」卡片联动左侧架构图高亮，配「聚光灯定位链」逐层举证（路由倾斜、显存 OOM 等典型故障场景），并提供「时光全景」浮窗回看整段训练关键事件。 |
| Config & Relation Observer（配置与关系观测台） | `Profiling_Insight_and_Tool/training-run-twin-standalone/config-relation-observer.html` | 四域配置仿真与关系观测：整网 / Model Architecture / MoE / Cluster 四区联动配置（Layer、DP/PP/TP/CP、专家数、集群规模等），支持一个 step 数据流播放、单卡显存容量测算(等距投影图 + 越界判定)；运行事件模式下切换为传播源 → 受影响域的溯源画布，并可查看关联的计算血缘。 |
| 训练管理平台 · 任务对比 | `Profiling_Insight_and_Tool/training-run-twin-standalone/TaskCompare.html` | 多任务横向对比：左侧任务勾选列表（含基线标记），右侧指标折线 / 看板对比不同训练任务（run）的表现差异，用于挑选最优任务或定位退化任务。 |

## 性能分析

| 工具名 | 路径 | 功能 |
| --- | --- | --- |
| 性能分析（MindStudioNext v3） | `Profiling_Insight_and_Tool/AI_Profiling_Tool/index_v3.html` | 综合性能分析工作台：计算图 / openPangu 整网图可视化、HBM 显存快照、多机多卡 step-trace Timeline 泳道、MFU 分析等多页签集成入口，是本目录下功能面最广的分析主入口。 |
| 训练性能分析报告 | `Profiling_Insight_and_Tool/AI_Profiling_Tool/report.html` | 性能分析报告形态：复用「性能分析（MindStudioNext v3）」的报告数据与图表，渲染为固定浅色、A4 文档流版式的可打印/导出 PDF 报告，供转发与存档，与工具形态互为入口（页面顶部「← 工具形态」可跳回 index_v3.html）。 |
| PTO 性能分析 · 任务时间对比 V2 | `Profiling_Insight_and_Tool/AI_Profiling_Tool/profileCompare.html` | 泳道对比查看器：以 Mix 子图核间同步为主题，构造同步竞争、调度空泡、FFN 流水失衡三类典型异常 run，双栏泳道对比展示任务条、等待段、同步弧线，用于性能问题模式的稳定演示与教学。 |
| HiF8 精度诊断工作台 · Ascend A5 | `Profiling_Insight_and_Tool/training-run-twin-standalone/hif8-precision-workbench-V3.html` | 低精度量化（HiF8/FP8）精度诊断：数值分布（原始 vs 量化后）、动态范围利用率、溢出率、量化 SNR、分布形态适配度等多维度分析，支持训练步回放观察量化误差的传播与累积。 |

> 说明：以上 7 个工具均为纯前端单文件页面（部分依赖同目录 `css/` `js/` 与仓库根级 `vendor/pto-design-system`），需通过本地 HTTP 服务打开，不能直接以 `file://` 方式访问。
