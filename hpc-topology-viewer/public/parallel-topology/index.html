Demo · v0.2 · 应用形态

并行拓扑可视化工具 · Demo

一个 step · 五幕：跟住一张卡从「128 个一模一样的进程」走到步末那一次梯度 AllReduce，把只做一次（开机/报到/备料）与每个 micro-batch 重来（进料/开算/接力）分开；第 2 幕放大的那一层是 openPangu 真图（真节点·真层级·真连边·真切分标注）。其余：一个切分一个视图（模板=参照系总图）：粒度做竖轴、rank 柱贯穿全高，归属边界线随维移动，索引五元组常驻；另有合成·卡阵、卡内解剖（容器+流）、映射（两个视角：双链映射——两条包含链级与级不对齐，四条并行映射的源头在四个不同逻辑层级、落点全是「卡」，把卡画成整个平面于是 TP 必须机内 / PP 可跨机当场可验；交集腔——那四条梁交出来的小长方体就是这张卡装的东西）、时间·流。默认 128 卡（tp2·cp1·pp4·dp16·ep8），URL 即状态，明暗主题，A1–A8 页内自检。

Pattern · 自包含 · 全屏画布

并行拓扑 Pattern —— 从一张网到 world 张卡

把 Demo 的「切分链」那一屏单独抽出来发布：全屏画布，一条链接就是一屏状态。五把刀（DP 复印 / PP 切段 / CP 切序列 / TP 锯片 / EP 分桶）各自独立开关、叠加而非切换；刀痕方向即轴——竖切=特征维 h、横切=序列维 s（CP 的 ctx 与 SP 的 token 切的是同一根轴，开着 CP 时那根轴上有两个除号：S/(CP×TP)）；打开 Rank 把五刀的交集收进 128 只卡壳，每只装它自己那份；关闭整网 清空卡内载荷——剩下的排列本身就是逻辑魔方，此刻直接把控制权交给 rubik-cube pattern 自己的工具条。正视 / 侧视由本页 SVG 渲染器原生重画（同一份真图 + 真切分表，不再嵌 sidecar）：正视标清 TP/SP/CP/DP/EP，侧视标清 PP；打开 Rank 显示卡的层级。契约在同级 pattern.json。

Cockpit · 驾驶舱

已有 pattern 真挂载 · 一条状态总线

不是文档：逻辑魔方与 rank 卡是 mount() 出来的真组件，切分链 / 时间·流 / 卡内解剖 / 交集腔是 iframe 里的真页面，纠正版 rank-deck 也在格里。一块大画布 + 切换轨：11 个组件按 A 刀对整网 / B 刀对卡空间 / C 映射 / D 时间 分组，一次看一个、切走不销毁（状态与 3D 场景都留着）。顶栏的配置 · 当前刀 · 选中卡是一条总线：换刀会同时换魔方的形态、真整网的切分模式与单维切分的维；一处选中卡，连隐藏着的组件也跟。URL 记住整屏。
