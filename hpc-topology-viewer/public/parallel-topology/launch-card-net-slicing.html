把「整网切分」那一屏单拎出来的自包含 pattern：全屏画布，一条链接就是一张可转的图。五把刀（DP 复印 / PP 切段 / CP 切序列 / TP 锯片 / EP 分桶）各自独立开关、叠加而非切换；刀痕方向即轴——竖切=特征维 h（TP / EP），横切=序列维 s（CP / SP）；SP 没有自己的开关，它复用 TP 组、跟着 TP 一起落下，但切的是另一根轴；attention 是唯一两把刀都过的地方，所以画成网格；打开 Rank 把五刀的交集收进 128 只卡壳，每只装它自己那份；关闭整网 清空卡内载荷——剩下的排列本身就是逻辑魔方，此刻直接把控制权交给 rubik-cube pattern 自己的工具条。正视 / 侧视由本页自己的 SVG 渲染器重画（同一份 OPENPANGU_GRAPH 真图 + net-sharding 真切分表，不再嵌 sidecar）：正视把 TP/SP/CP/DP/EP 逐算子标在轴上，侧视把 PP 分段、Dense→MoE 换挡、mHC residual 主干沿层深铺开；顶视看不到 TP 的两层是对的——三个正交视图各看一个平面，被压掉的那根轴落在深度方向。URL 即状态（cuts / vtab / card / net / sel / embed），不认识的参数一律忽略、非法值退回默认。
