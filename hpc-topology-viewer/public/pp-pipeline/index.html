PP 的两张脸 —— 用 rank 看流水线

流水并行（PP）是四个切分维里唯一有序、不能折叠的那根轴——它本质是被空间化的时间。 一张 rank×时间的网格就能同时说清三件事：一个 micro-batch 的因果链是一条斜线、 不同 micro-batch 错开重叠就是并行、两角的空白就是气泡。左边空间脸回答「谁装哪几层」， 右边时间脸回答「谁在什么时候算」——两张脸唯一共享的轴，就是 pp_rank：rank 门牌号 (pp,dp,cp,tp) 里的 PP 那一位。这张图不画单张 rank——每一格是 pp_rank 相同的一整组卡 （下面默认 128 张）锁步做同一件事，另外三位 TP/DP/CP 折进了每一格。停在格子上能看到其中一张的完整门牌号。

为什么这根轴不能折

TP/DP 组内成员可互换、锁步做同样的事，画一个代表就够。PP 三条都不成立：每个 stage 装不同的层、 是有向链（同一 micro-batch 必须 stage k 先于 k+1）、任一时刻处于流水线不同位置。折了，斜线、气泡就都没了。

F0 / B0 怎么读

F = 前向、B = 反向；数字是 micro-batch 编号（不是 stage 号、不是层号）。所以 F0 与 B0 是同一批数据的一去一回：F0 沿 stage 往上爬，到顶算完 loss，B0 再一路往下——点 mb 0 高亮出来是个 先上后下的 Λ。同一个 F0 在每个 stage 各出现一次，那就是它在流水线里走。

重叠 = 并行；空白 = 气泡

不同 micro-batch 的斜线在横轴上错开重叠，重叠处就是流水线的并行。左下 warmup、右上 cooldown 两片空白是气泡， 占比随 micro-batch / PP 变化——把 GA 拉大，气泡就变小。

注意 1F1B 和 GPipe 的气泡完全一样。切换调度，makespan 与气泡占比一个都不变—— 1F1B 省的是显存：看「峰值在飞 micro-batch」从 micro-batch 数掉到 PP。

这里面有没有单张 rank？

没有。每一格是 Stage s = pp_rank 相同的一整组卡（默认 128 张真实 rank）锁步做同一件事。 图上唯一的 rank 信息是 pp_rank 这一位——门牌号 (pp,dp,cp,tp) 里的 PP； 另外三位 TP/DP/CP 折进了每一格（调上面三个数看折了多少）。点左边任一 Stage 盒子，就能把那组卡摊成 dp×tp 网格、看到每张的完整门牌号与 global_rank。

读法约定：y 轴是 pp_rank（0 在底，向上递增），x 轴是时间（每格 1 个时间单位， 这里把反向也简化成 1 个单位；真实反向约为前向的 2 倍）。气泡比取自实际排布 (T−2M)/T， 与参照系里的经验式 (PP−1)/GA 是同一件事的精确版与口算版。对应参照系 FIG 15（多 rank 时间线）与 FIG 16（PP 铰链）。
